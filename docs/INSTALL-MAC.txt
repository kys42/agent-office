Agent Office — macOS preview

1. Drag Agent Office.app to Applications.
2. Open Agent Office from Applications.
3. Existing settings and local session history stay in
   ~/Library/Application Support/Agent Office.

This preview is ad-hoc signed, not Developer ID signed or Apple-notarized.
If macOS blocks an Internet download, inspect its source and use System
Settings > Privacy & Security > Open Anyway to allow this app.
Do not disable Gatekeeper or delete your app data.

To update: quit Agent Office from its tray menu first, then replace the app
in Applications. Closing its office window leaves the tray/pet running.
To roll back: quit and replace the app with the previous verified version.
Keep a backup of the data directory before rolling back across DB changes.

Apple Silicon (M-series) uses arm64. Intel Macs use x64.
Version, source commit and signing status are in
Agent Office.app/Contents/Resources/release.json.

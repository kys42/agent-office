# Agent Office · 작은 사무실 캠페인

상태: **제작·검토용 초안 / 미발행**. 계정·다운로드 목적지·게시 시점은 미지정이다. 실제 공개 릴리스 확인 없이 다운로드 링크나 출시일을 만들지 않는다.

대상은 Claude Code·Codex·OpenClaw 세션을 여러 개 사용하는 개발자다. 전달할 한 문장은 **“터미널 사이를 돌며 확인하던 AI 동료들이 바탕화면에 모인다.”**

## 발행 구성

첫 이미지에는 짧은 훅 하나만 둔다. 다음 이미지에서 실제 데스크 펫·사무실·업무 카드 캡처를 보여준다. 코드가 가득한 데스크톱 전체를 작은 SNS 카드 안에 넣어 글씨를 읽을 수 없게 만들지 않는다. 실제 기능 캡처는 합성 세션으로 만들고, 이미지별 대체 텍스트를 제공한다.

영상 후보는 **데스크 펫 → 책상 줄 펼치기 → 손 든 동료 → 업무 카드에서 요청·진행·응답 확인**의 한 흐름이다. 앱이 직접 모든 에이전트를 실행하거나 승인해 주는 것처럼 편집하지 않는다.

게시 계정은 제품 소유자의 계정으로 확정해야 한다. 독립 사용자인 척하는 후기, 만들어 낸 사용량/성능 수치, 가짜 사용자 추천은 쓰지 않는다. 실제 발행 때 플랫폼별 최신 글자·미디어 규격과 권한을 다시 확인한다.

## 권장 편집 순서

1. 커버와 한 줄 소개로 무엇인지 알린다.
2. 실제 UI 세 장으로 사무실 → 작업 카드 → 데스크 펫의 사용 장면을 보여준다.
3. 블로그에서는 상태의 의미와 전송/권한 범위를 설명한다.
4. 검증된 공개 릴리스 링크가 준비된 뒤 계정에 맞는 CTA를 붙인다.

초안에 남긴 제품 제약은 삭제해서 과장하기보다, 긴 설명은 블로그로 연결한다. 최적화 수치는 새 기준선과 같은 조건으로 측정하기 전에는 홍보에 사용하지 않는다.

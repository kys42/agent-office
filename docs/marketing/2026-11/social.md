# SNS 초안

제품 소유자 계정용. 아직 게시하지 않았으며 계정과 공개 목적지는 확정 전이다. 아래 본문은 그대로 검토할 수 있는 초안이다.

## X · 첫 소개

AI한테 일을 맡겼는데, 이번엔 내가 터미널 순찰 중.

Agent Office는 Claude Code·Codex·OpenClaw의 실제 세션을 바탕화면의 작은 동료로 보여줘요.

일하는 친구, 나를 기다리는 친구, 방금 답변을 마친 친구.
책상을 누르면 대화까지.

내 AI 팀에도 사무실을 만들어봤습니다. 🪑

이미지: 브랜드 커버 + 실제 합성 사무실 캡처. 일러스트는 캡션에 구분한다.

## Threads · 사용 장면

에이전트를 여러 개 켜두면 이상한 일이 생겨요.
코드는 AI가 쓰는데, “누가 끝났지?”는 내가 계속 확인하게 됩니다.

그래서 Agent Office를 만들고 있어요.

Claude Code·Codex·OpenClaw 세션에 작은 책상을 하나씩 줍니다. 같은 프로젝트 친구들은 모여 앉고, 질문이 있는 친구는 손을 들어요. 누르면 내 요청·진행·최종 응답을 업무 카드에서 볼 수 있고요.

전체 사무실이 필요 없을 때는 화면 구석의 데스크 펫으로 작게 두면 됩니다.

귀여운 책상에서 시작했지만, 진짜 하고 싶었던 건 “지금 내가 봐야 할 일”을 찾기 쉽게 만드는 거였어요.

이미지: 실제 데스크 펫/책상 줄/업무 카드 3장. 모두 합성 예시라고 마지막 캡션에 명시한다.

## 기능 포스트 · 의미가 보이는 진행

`exec 실행 중`만 보여주면, 그래서 뭘 하는지는 여전히 모르겠더라고요.

Agent Office는 에이전트가 남긴 진행 설명을 먼저 보여줍니다.
내 요청, 진행 상황, 최종 응답을 나누고 도구 기록은 필요할 때 펼쳐요.

새로운 AI 요약을 만드는 대신, 원래 대화의 공개 메시지를 읽기 좋게 모았습니다.

이미지: 업무 카드의 요청·진행·최종 필터가 보이는 실제 데모 캡처.

## 기능 포스트 · 바탕화면의 작은 팀

같은 프로젝트의 에이전트들은 옆자리.
같은 브랜치는 긴 책상.
서브에이전트는 옆의 작은 보조 책상.

Agent Office에서는 세션의 관계가 자리 배치가 됩니다.
터미널 제목을 하나씩 읽는 대신, 누가 한 팀인지 눈으로 볼 수 있게요.

이미지: 합성 프로젝트 구역과 보조 책상을 확대한 실제 캡처. 없는 관계를 이미지에 추가하지 않는다.

## 짧은 영상 대본 · 15초 구성 후보

| 구간 | 화면 | 자막 |
| --- | --- | --- |
| 0–3초 | 합성 터미널 여러 개 → 화면 구석 펫 | AI는 일하는데, 나는 창을 순찰 중? |
| 3–6초 | 실제 데스크 펫에서 책상 줄로 | 내 AI 팀을 바탕화면으로 |
| 6–10초 | 손 든 동료와 진행 말풍선 | 누가 나를 기다리는지 |
| 10–13초 | 업무 카드 요청·진행·응답 | 무엇이 진행됐는지 |
| 13–15초 | 작은 펫으로 돌아오기 | Agent Office · 작은 사무실, 실제 세션 |

위 표는 촬영/편집 대본이며 완성 영상으로 표기하지 않는다. 지원되지 않는 공급자 동작이나 실제로 보내지 않은 메시지의 성공 장면을 합성하지 않는다.

## 자주 나올 질문에 대한 짧은 답

- **그냥 움직이는 펫인가요?** 실제 로컬 세션 기록을 읽어 상태·프로젝트·대화를 보여줍니다. 화면은 픽셀 동료로 표현해요.
- **새 AI 서비스에 로그를 올려야 하나요?** 기본 수집과 저장은 로컬입니다. GitHub 상태·사용량 조회와 명시적으로 켠 원격 연결은 각 기능의 외부 통신을 사용해요.
- **직접 명령도 보낼 수 있나요?** 지원되는 데스크톱/터미널 연결 대상에서 가능합니다. 공급자와 실행 환경에 따라 다르며, 모든 세션의 입력·승인을 자동 처리하는 기능은 아닙니다.
- **휴대폰에서도 되나요?** 실행 중인 컴퓨터의 모바일 웹을 켜고 같은 Tailscale에서 접속하는 방식입니다. 컴퓨터가 꺼지거나 잠자기에 들어가면 접속할 수 없어요.

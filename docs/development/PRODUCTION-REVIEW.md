## 1회차 · 설치 신원과 연결 복구

- 확인: 최신 main의 macOS 패키징은 임시 ad-hoc 서명이 기본이었다. 이 Mac의 별도 Developer ID 설치본과 다른 컴퓨터의 main 빌드는 같은 배포 경로가 아니었다. 구체적인 다른 기기의 설치본은 미확인.
- 확인: worker 종료는 콘솔 로그만 남기며, 기존 화면은 이전 스냅샷을 계속 보여 준다. 웹 폴링 오류도 숨겨진다.
- 개선: 정식/임시 패키징 명령 분리, 앱 내부 빌드·권한 안내, 실패를 드러내고 기존 데이터는 유지하는 재연결.
- 검증: 서명 설정/메타데이터 whitelist/권한 URL allowlist/worker crash 자동 복구 테스트 통과. Apple preflight(2026-10-29)에서 Developer ID와 공증 API 접근 유효 확인.

## 2회차 · 실제 사용자 흐름과 UI/UX

- 확인: 이미지 단독 Codex 요청은 원본 기록 제한 때문에 UI에서도 전송 확인이 보이지 않았다. 카드를 다시 열 때 유지하던 확인 표시도 앱을 재시작하면 사라졌다.
- 개선: 이미지 장수와 공급자 기록 제한을 표시하고 로컬 전송 확인을 복구한다. OS 권한은 실제 승인 상태로 오인할 체크 표시 대신 목적·시스템 설정 링크로 안내한다. 실제 앱 서명/빌드 정보는 설정의 연결 탭에서 한 번 읽는다.
- 화면: 기본 연결 화면은 짧게 유지하고 권한 안내를 펼침 요소로 제공한다. 라이트/다크, 1050px 창, 480px 너비, 키보드 Enter로 펼치기, 로딩/실패/재시도 상태를 확인했다.
- 검증: 당시 관련 UI 23개 통과. 뒤의 개인정보·다중 창 보강을 포함한 전체 UI 검증에서 다시 확인했다.

## 3회차 · 회귀와 릴리스 검수

- 독립 코드 리뷰: 서명·패키징과 연결·전송 경계를 나눠 읽기 전용 검토했다. 서명 문서의 옛 명령, 전송 본문 추가 보관, 다중 창 정합성 우려를 반영했다.
- 개선: full-text 전송 확인 저장을 제거했다. 영속 저장은 UUID·세션 ID·시각·이미지 장수·기록 제한과 SHA-256 대조 지문만 담는다. 다른 창/재시작에서는 일반적인 전송 확인으로 표시한다. 같은 기록 하나는 한 번만 대응하고 재전송하지 않는다.
- 개선: 창별 키와 Web Locks로 동시 대응을 직렬화한다. localStorage 불가 시 메모리에 유지한다. 최대 50건, 유효기간 30분이며 다음 읽기/시작 시 만료 항목을 지운다. 대응 완료 표시는 최대 1,000건으로 제한한다. 기기 분실·디스크 접근으로부터 암호화하는 기능은 아니며, 원래 대화·기존 초안 정책과 구분한다.
- 개선: 수집기가 스냅샷 하나를 보낸 직후 다시 죽는 반복도 재시도 한도를 소비한다. 60초 안정 실행 뒤에만 예산을 초기화한다. 대기 전송이 없는 평상시에는 전송 확인 대조가 localStorage를 훑지 않는다.
- 기각/검증: demo 전환 후 과거 resync가 살아날 수 있다는 리뷰 우려는 generation/cleanup guard로 보호되어 있었다. 실제 전환 → 재시도 시점 경과 → 오래된 health 이벤트 시험을 추가했고 요청/오류가 데모로 넘어오지 않았다.
- 검증: 단위 **806개**, 전체 UI **431개**, typecheck·production build·format 통과. Impeccable 변경 UI 탐지 결과 `[]`. 서명 리뷰에서 node-pty의 `pty.node`/`spawn-helper`가 서명 대상에 들어가고 실행 권한을 복원하는 것 확인.
- Native: 합성 3개 공급자/별도 프로필의 실제 Electron smoke와 MCP smoke 통과. 설치 신원 IPC와 임의 권한 URL 거부도 검증했다. 첫 native 실행의 바닥 책상 버튼 탐색 timeout은 재실행에서 재현되지 않았다. 실패 시 창/스크린샷 근거를 남기도록 smoke를 보강했으며, 최종 signed DMG 설치본에서도 재검수한다. OS 포커스 검수는 사용자 작업 방해를 피하는 quiet 실행에서 생략했으므로 Dock/키보드의 실제 포커스 보장으로 확대하지 않는다.

## 검증 산출물

실행 로그와 합성 스크린샷은 검수 worktree의 `.local/production-*`에 둔다. `.local`은 Git에 포함하지 않는다. PR에는 소스/정책과 실행 결과를 남기고, 서명 산출물은 `release/`의 source SHA·manifest·체크섬으로 식별한다.

## 출시 판단의 경계

- 서명은 앱 신원의 안정화이지 OS 권한 자동 승인이나 다른 컴퓨터로의 권한 복사가 아니다.
- 처음 설치한 기기의 권한 승인과 같은 기기의 업데이트 후 반복 승인을 구분한다.
- 공개 배포·자동 업데이트·다른 물리 기기 검증은 실제 수행 근거가 있을 때만 완료로 기록한다.
- 보존 중인 기존 main의 미커밋 문서, 기존 서명 릴리스/개인 데이터, 다른 기능의 열린 PR은 임의로 삭제하거나 종료하지 않는다.

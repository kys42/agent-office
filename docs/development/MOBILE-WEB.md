# 모바일 웹

실행 중인 Desktop main이 켜고 끄는 선택 기능이다. 기본 꺼짐이며 기존 HTTP 개발 미리보기나 LAN exporter와 다른 API·포트를 사용한다. 별도 수집기나 동기화 서버를 만들지 않고 같은 `ServiceBridge`에서 로컬/연결된 사무실을 읽는다. 기존 개인 DB 스키마와 원본 로그는 변경하지 않는다.

## 사용

1. 컴퓨터와 휴대폰을 같은 Tailscale에 연결한다.
2. 컴퓨터 앱의 설정 → 모바일 웹에서 Tailscale 주소와 포트(기본 4321)를 선택하고 **웹 버전 켜기**를 켠다. `127.0.0.1`은 이 컴퓨터의 브라우저 검수용이다.
3. 표시된 주소를 휴대폰에서 열고 **접속 코드**를 입력한다. 접속 코드는 URL에 넣지 않는다.
4. 사무실·프로젝트·상태·검색으로 동료를 고르고 대화를 연다. 원래 앱에서 전송 가능한 대상만 보낼 수 있다. Codex Desktop은 이미 열린 지원 대화여야 한다.
5. 웹 버전을 끄거나 코드를 바꾸면 로그인 세션이 해제된다. 이미 전송된 요청은 취소되지 않는다. 앱을 종료하면 웹 서버도 종료된다.

선택 가능한 주소는 loopback 또는 이 컴퓨터 인터페이스의 Tailscale 범위 IPv4(100.64.0.0/10)다. wildcard·공용 IP·일반 LAN 바인딩은 제공하지 않는다. 직접 HTTP를 사용하고 Tailscale 구간은 WireGuard 암호화를 사용한다. 이 HTTP 서버를 공용 역방향 프록시로 노출하거나 임의 Host/Origin을 허용하도록 변경하지 않는다. Tailscale Serve/Funnel과 계정 연동은 이번 범위 밖이다. 세션 쿠키는 HttpOnly/SameSite=Strict이며 직접 HTTP라 Secure 속성은 붙이지 않는다.

## API와 권한

`server/mobile/server.ts`는 필요한 경로만 제공한다. 모든 개인 API는 POST JSON, 정확한 Host·Origin, `X-Agent-Office-Mobile: 1`을 요구한다. CORS를 허용하지 않는다. 정적 mobile 페이지와 빌드 자산에는 CSP·frame 차단·no-store가 적용된다. 임의 RPC, 파일 경로, 설정 변경, 쉘, 승인 자동 응답, 터미널 초안 교체 API는 없다.

| 경로 `/mobile/api/` | 동작 |
| --- | --- |
| login / logout | 접속 코드로 최대 12시간 세션 생성·해제 |
| state | 가시 동료의 제목·상태·프로젝트·사무실·최근 설명만 반환 |
| detail | 최근 40개 또는 이전 페이지의 사용자 요청·진행·최종 응답. `tools: true`일 때 도구 기록 포함 |
| targets | 전송 가능 여부와 Desktop/대기열 표시 정보 |
| send | 요청 ID를 포함한 사용자 메시지 전송 |
| receipt | 기존 요청의 접수 결과 조회. 전송하지 않음 |

조회와 전송 모두 현재 가시 세션을 확인한다. 제외 프로젝트·꺼진 공급자·가려진 동료는 읽지 않고, 개인정보 가림이 켜지면 빈 목록을 반환하고 상세와 전송을 거절한다. 원격 서버의 대화·전송 공유 권한을 그대로 적용한다. 연결이 끊긴 원격 대화는 새 조회/전송을 거절하고 목록에 오래된 상태를 표시한다. 네이티브 경로·핸들·인증정보는 DTO에 넣지 않는다. 휴대폰에 이미 전달한 내용의 회수는 보장하지 않는다.

기본 접속 코드는 192비트 난수다. 로컬 프로필 파일에는 사용자가 지정한 8~64자의 공백 없는 ASCII 코드도 저장할 수 있다. 실제 접속 코드는 저장소에 커밋하지 않는다. 인증 시도는 서버당 분당 20회, 세션 16개, 세션당 분당 240회, 동시 요청 24개, 본문 128KB로 제한한다. 앱 재시작·끄기·코드 변경은 모든 세션을 무효화한다. 앱 설정의 기존 메시지 보내기 권한을 웹에서 켤 수 없다.

## 전송과 저장

Desktop의 `sendTargets`/`sendMessage`를 IPC와 웹이 함께 사용한다. 원래 공급자 어댑터가 대상과 상태를 다시 확인한다. 네트워크 권한 검사는 Codex dispatch 직전, Claude 붙여넣기 직전과 Enter 직전에 반복한다. LAN 전송은 기존 federation command API와 해당 서버 권한을 그대로 거친다. 원격 대상 조회 뒤 실제 HTTP 전송 직전에 worker가 main의 요청별 인증 콜백을 다시 확인한다. 콜백이 없던 기존 Desktop 경로는 그대로 유지하며, 확인 응답 유실·타임아웃은 전송을 막는다.

Desktop 프로필에 다음 두 파일만 별도로 둔다.

- `mobile-web.json` (0600): 켜짐·주소·포트·접속 코드. 기능을 사용하지 않으면 생성하지 않는다.
- `mobile-commands.sqlite` (0600): 요청 ID·대상/내용 해시·접수 상태. 메시지 본문은 저장하지 않는다. 전송 시작 전에 durable uncertain을 기록하고, 접수 확인 후 sent로 갱신한다. 같은 ID와 내용은 결과만 반환하고 다른 내용 재사용은 거절한다. 오래된 요청을 자동 삭제하지 않으며 10만 건에서 새 요청을 막는다.

응답 유실이나 앱 종료 뒤 uncertain 요청은 다시 dispatch하지 않는다. 모바일의 **접수 확인**은 기록만 조회한다. 원래 대화를 확인한 사용자가 명시적으로 미확인 상태를 해제한 뒤에만 새 요청을 만들 수 있다. 전송 접수는 에이전트 작업 완료와 다르다. 터미널에 작성 중인 글이 있으면 컴퓨터에서 확인하도록 안내하며 원문을 모바일 확인창으로 전달하지 않는다.

모바일 초안·미확인 요청은 기기 브라우저의 sessionStorage에 대화별로 유지한다. 로그아웃하면 지우고, 저장소를 사용할 수 없으면 현재 화면 메모리에서만 유지한다. 서버 설정·개인 DB·원본 대화에 초안을 저장하지 않는다.

## 공통 대화 UI와 호스트 경계

`src/components/chat/`의 `ConversationMessage`, `ChatMarkdown`, `ChatComposer`, 메시지 CSS를 Desktop 팝업·모바일이 함께 사용한다. 메시지 분류·접기·전체 복사·Markdown·한글 조합 중 Enter 방지는 공통이고, 북마크·초안 확인·접수 확인은 각 화면이 소유한다. Desktop의 아티팩트·외부 링크 열기는 `src/lib/chat-actions.ts`가 담당한다. 모바일은 검증된 HTTP(S) 링크와 브라우저 복사만 사용하며 `src/mobile/transport.ts`를 통해 모바일 API에 접근한다. 직접 Tailscale HTTP에서 Clipboard API가 없으면 클릭 시 textarea 복사로 대체한다.

공통 UI는 Electron/RPC/서버 코드를 import하지 않는다. 번들 경계 테스트로 이 계약을 검증한다. 향후 APK의 WebView 셸도 이 UI와 transport 경계를 재사용할 수 있지만 APK 패키징·네이티브 인증/링크 정책은 아직 구현하지 않았다.

기본 상세 조회는 도구를 서버에서 제외한 뒤 페이지를 자른다. 따라서 도구 호출이 많아도 요청·진행·답변이 페이지에서 밀려나지 않는다. 도구 체크박스를 켜면 새 보기로 재조회한다. 전환 전 응답과 전송 완료 후 갱신도 현재 보기와 일치해야 한다. 원격 구서버는 필터 인자를 무시할 수 있으므로 수신 측에서도 필터하지만, 전송량 절감과 필터 전 페이지 선택에는 새 exporter가 필요하다.

열린 대화는 최근 최대 400개와 본문 합계 512,000 UTF-16 코드 단위 중 먼저 도달하는 상한을 사용한다. 이벤트 하나는 서버에서 64,000자로 자르고 발췌 표시한다. 상한에 닿으면 이전 페이지 버튼을 비활성화한다. 화면의 펼친 메시지 ID도 현재 창 안의 것만 유지한다. 이는 보관량 제한이며 실제 JS 힙/RSS가 같은 바이트 수라는 뜻은 아니다.

## 화면과 검증

`mobile.html`은 별도 Vite entry지만 같은 앱 번들에 포함된다. `src/mobile/`는 토큰과 상태/공개 대화 분류를 재사용하고 작은 화면에서 목록↔대화, 넓은 화면에서 양쪽 열을 제공한다. 대화는 사용자가 하단에 있을 때만 새 메시지를 따라가고 이전 페이지 로딩 시 위치를 유지한다. 원격 대화는 매번 현재 허용된 스냅샷으로 교체하며 조회 실패 시 이전 전문을 지운다. 로컬 새 페이지가 이전 내용과 이어지지 않으면 최신 페이지에서 다시 시작해 이전 페이지 접근을 유지한다. 탭이 숨겨지면 5초 조회를 멈춘다. Markdown 원시 HTML·외부 이미지는 실행하지 않는다. 모바일 문구는 브라우저 언어에 따라 한국어/영어로 표시한다.

- `tests/detail-retention.test.ts`: 10,000회 누적/캐시 쓰기, 개수·본문 크기·TTL·LRU 상한, 도구 제외 전 페이지 선택.
- `tests/chat-boundary.test.ts`: 모바일 번들의 Desktop RPC/서버 의존성 차단.
- `tests/mobile.test.ts`: 기본 꺼짐, 직접 HTTP 인증/Host/Origin, DTO/가림/범위, 세션 회수, 재시작 후 중복 방지, 불확실 결과, 권한 회수 중 dispatch 차단.
- `tests/terminals.test.ts`: 모바일 권한 회수 시 붙여넣기/Enter 차단, 기존 기본 경로 회귀.
- `tests/ui/mobile.spec.ts`: 390px 목록/필터/대화/전송/초안·미확인 결과 복구/가림.
- `scripts/mobile-smoke.mjs`: 격리 Electron의 opt-in 서버 → 휴대폰 크기 Chromium → 합성 Codex Desktop owner의 정확히 한 번 전송, 코드 변경과 종료. 실제 사용자 대화에 메시지를 보내지 않는다.

운영 Tailscale 주소에서 페이지/인증/조회 확인과 실제 휴대폰 Safari의 터치·키보드 검수는 별도 근거로 기록한다. Chromium 통과를 실제 iOS 기기 검수로 표현하지 않는다.

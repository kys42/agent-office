# Agent Office — 아홉 가지 장면

- Round 02 / v1 / 2026-10-04
- 범위: 사무실 메인 화면 디자인 탐색 9안. 예시 데이터와 로컬 시연 동작을 사용하는 정적 HTML 프로토타입.
- 기존 E 기반 앱과 실제 세션 수집기에는 변경 없음. 모든 후보는 탐색 중이며 사용자 선택 전.

## 열람

기존 미리보기 서버: http://127.0.0.1:4319/design/office-themes-2026-10-04/

테일스케일: https://your-device.your-tailnet.ts.net:4319/design/office-themes-2026-10-04/

ZIP을 푼 폴더에서 아래 명령으로 따로 열 수도 있습니다. 외부 패키지나 네트워크 폰트는 필요하지 않습니다.

```sh
python3 -m http.server 4390 --bind 127.0.0.1
```

그 뒤 http://127.0.0.1:4390/index.html 을 엽니다. 기본 디자인 크기는 1280 × 800입니다. 좁은 화면은 전체 구도를 비례 축소합니다.

- index.html / gallery.js / gallery.css: 전체 카탈로그, 분류, 두 시안 비교
- overview.html / overview.js: 9개 안을 한 화면에서 비교
- data.js: 공통 예시 세션, 콘셉트 설명, 확인한 레퍼런스
- office.js: 각 안의 독립 화면 구성과 공통 대화·대기·보관 시연
- office.css: 방향별 레이아웃·가구·색·재질·문자와 상세 모달
- manifest.json: 편집 가능한 카탈로그와 원본 연결
- assets/: 기존 캐릭터·픽셀 가구, 로컬 폰트, 비교 스크린샷, 기준 화면

## 비교 가능한 동작

캐릭터 또는 소식 클릭 → 대화 상세. 사용자 요청과 에이전트 진행 메시지 구분. 더보기/접기, 보조 도구 기록 펼치기, 자리 고정 표시, 대기실과 보관함 기록 열람. 소식 패널이 있는 안의 최근/자주 사용 정렬은 책상을 움직이지 않습니다.

예시에는 6개 사무실 세션, 1개 대기 세션, 1개 보관 세션이 있습니다. 실제 로컬 로그·비공개 작업 기록을 사용하지 않습니다. GitHub 카드는 기존 저장소 이슈 목록으로 연결되는 **링크 표현 예시**이며, 세션이 만든 실제 PR/이슈를 주장하지 않습니다. 자리 고정은 상세 모달 내 시연 상태이며 저장되거나 실제 앱으로 반영되지 않습니다.

## 기준안과 원본

기존 선호 방향 E 및 현재 앱은 수정하지 않았습니다. assets/baseline-e.png는 기존 docs/images/office.png의 복사본입니다. 원래 디자인 소스는 프로젝트의 references/design-source/design/E-Office.dc.html에 보존되어 있습니다. 해당 기준안은 새 9안에 포함하지 않습니다.

## 에셋

세 캐릭터와 픽셀 사무실은 기존 Agent Office 프로젝트 자산을 그대로 재사용합니다. 벡터 책상, 창문, 화분, 건물 등은 이 시안의 office.js/office.css 안에서 직접 제작한 편집 가능한 SVG/CSS입니다. IBM Plex Sans KR는 프로젝트에 설치된 @fontsource 패키지의 폰트이며 라이선스는 assets/FONT-LICENSE.txt에 있습니다.

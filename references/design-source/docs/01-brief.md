# 01. 초기 기획 (오더 원문 + 정리)

> 작성: 2026-10-03 · 출처: 기획자 오더(대화) 원문을 그대로 옮기고, 아래에 요구사항으로 정리

## 오더 원문

> 내 클로드코드 코덱스 오픈클로 등 에이전트들이 일하고 있으면 걔네 세션이 사무실에서 일하고 있는것처럼 보여주는 데스크탑 펫에 오피스 더한 느낌의 프로그램을 만들고싶어 기본적으로 코덱스펫 같은것처럼 데탑에 쪼꼬미들이 뽀롭ㄹ뽈 떠있고 누르면 사무실에서 걔네가 일 뭐 개발중이면 일하고잇고 아니면 오래된세션은 퇴근하는느낌 걔네가 뭐하고이쓴ㄴ지도 위에 말풍선이나 이런거 에 뜨면 좋고 지금 당장 어떻게 걔네를 다 연동할지보다는 디자인에 집중해서 너가 최고의 디자이너라고 생각하고 유아이유엑스 디자인해봐 모든걸쏟아부어 여러개 시안 줘됴 좋아
>
> 내가 사용하는 에이전트가 많으니까 어떤게 뭘하고있는지 간단하게 보명서도 귀여운느띰
>
> 세션은 그냥 돌아가고잇는건백그라운드에서 알아서 모니터링 된다치고 데이터는 목업으로 구성해너ㅏ도 대거 귀야운 캐릭터들은 코덱스펫처럼 정해진 캐릭터 동작 시트 넣으먄 나중에 갈아끼울수도 잇을거고
> 흠 일단은 모든걸 고려할필요는 없음 멋진 디자인컨셉들이 보고싶어

### 추가 오더

> 세션 이름이 있으면 그거 보여주거나 직접 이름붘일수잇어도 좋을듯

> 흠 게더타운 스타일 로 만들어볼수는없을라나 사무실이 잇고 애들이 와서 앉고 그런느낌 뽈뽓뽓 귀녑게 돌아다니고 대신 저건 너무 배경이크고 우리건 좀 더 겅간이 좁고 애들이 크게 보여도 될듯 그리거 말풍선 이나 상태 이런게 훨씬 잘 보이게하고

## 한 줄 정의

여러 AI 코딩 에이전트(Claude Code, Codex, OpenClaw 등)의 세션 하나하나를 **쪼꼬미 캐릭터**로 만들어, 데스크탑 위에 띄우고 **사무실**에서 일하는 모습으로 보여주는 데스크탑 펫 + 오피스 앱.

## 요구사항

| # | 요구 | 비고 |
|---|---|---|
| R1 | 데스크탑에 쪼꼬미들이 떠 있다 | 코덱스펫처럼 항상 위에 뜨는 작은 펫 |
| R2 | 누르면 사무실 화면이 열린다 | 펫 = 세션, 사무실 = 전체 현황 |
| R3 | 상태가 행동으로 보인다 | 개발 중이면 일하는 모습, 오래된 세션은 **퇴근** |
| R4 | 뭘 하는지 말풍선으로 보인다 | 지금 하는 작업을 짧게 |
| R5 | 에이전트가 많아도 한눈에 | 어떤 게 뭘 하는지 간단히, 그러면서 귀엽게 |
| R6 | 캐릭터는 동작 시트로 교체 가능 | 정해진 규격의 시트를 넣으면 갈아 끼움 |
| R7 | 세션 이름 표시 + 직접 이름 붙이기 | 추가 오더 |
| R8 | 게더타운처럼 돌아다니는 사무실 | 공간은 좁게, 캐릭터는 크게, 상태·말풍선은 훨씬 잘 보이게 (추가 오더) |

## 범위

- **이번에 하는 것:** UI/UX 디자인 컨셉 여러 개, 목업 데이터, 캐릭터 동작 시트 규격
- **나중에 하는 것:** 실제 에이전트 연동(세션 모니터링은 백그라운드에서 된다고 가정), 앱 구현
